# 测试与反馈 / Testing and feedback

## 中文

这个网站已经进行过真人内测。我会继续根据实际使用中的反馈调整功能和操作细节。

项目也保留过自动化检查记录：2026-10-01 的记录显示，30 组自动化回归和 3 组专项测试通过。这部分使用 JSDOM 和模拟服务，主要用于发现代码和流程中的问题。

真人内测与自动化检查是两回事，也会互相补充。不能因为自动化用了模拟服务，就说项目没有真人测试；同样，也不会把已有内测说成所有设备、网络和模型都没有问题。

这里暂不写内测人数、完成率或具体模型名单，因为还没有在这份公开说明里整理这些数据。后续如果整理测试反馈，会区分用户实际遇到的问题、已经修复的内容和仍在改进的地方。

## English

The website has undergone internal testing with real users. Their feedback informs ongoing improvements to features and usability.

The October 1, 2026 technical record also reports 30 automated regression groups and 3 focused checks passing with JSDOM and mock services. Those checks help find code and workflow problems.

User testing and automation complement each other. Mock-service tests do not mean there has been no real-user testing. Existing internal testing also does not mean every device, network, or model has been validated.

Participant counts, completion rates, and specific model coverage are not listed here because those details have not been compiled for this public guide. Future feedback summaries should separate observed issues, completed fixes, and remaining work.
