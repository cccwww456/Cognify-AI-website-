# CognifyAI

[介绍网站](https://cccwww456.github.io/Cognify-AI-website-/%E4%BB%8B%E7%BB%8D%E7%BD%91%E7%AB%99/) · [产品网站](https://cccwww456.github.io/Cognify-AI-website-/%E4%BA%A7%E5%93%81%E7%BD%91%E7%AB%99/) · [English](README.en.md)

我希望做一个让人更会用 AI 的网站。不是把问题发出去、拿到答案就结束，而是学着和 AI 一起把需求理清楚、把事情做下去，再判断结果哪里好、哪里还要改。

所以我做了 CognifyAI。它把对话、记忆、画布和项目练习放在一起，希望 AI 能成为工作中的协作伙伴。

## 两个网站，怎么选？

- **介绍网站**：先看看 CognifyAI 能做什么，适不适合你的工作。
- **产品网站**：直接进入体验。介绍网站里的“开始对话”也会跳到这里。

上面的在线链接对应我的 GitHub 仓库，需要 GitHub Pages 发布成功后才能访问。刚上传文件但还没开启 Pages 时，链接可能显示 404。

## 谁可以用？

如果你已经用过 AI，想把它用得更顺手，可以来试试。设计、开发和研究是目前重点考虑的场景，但不局限于这三类人。

你可以在对话中整理想法，决定哪些内容继续让 AI 参考；也可以建立项目，把任务拆成步骤，在对话里推进，在画布里查看和修改产出。想先熟悉方法，可以从网站、图片或视频相关的教学项目开始。

## 怎么开始？

第一次进入可以先用体验模式。这里的内容是准备好的示例，方便了解流程，不是针对任意要求实时生成。

想用真实 AI，可以在“API 设置”里填入自己的服务地址、模型名称和密钥。图片、视频服务需要分别配置。能否连接取决于对应服务是否支持网页调用，费用也由服务商决定。

目前“登录”按钮只是进入产品的入口，还没有账号登录和云端同步。记录保存在当前浏览器，重要内容记得导出或备份。换电脑、清除浏览器数据，或者从本地切换到线上地址，都不会自动带走原来的记录。

我会继续结合实际反馈，把操作流程和使用细节做得更顺。具体方向放在 [未来计划](ROADMAP.md)，测试情况放在 [测试与反馈](TESTING.md)。

## 下载后怎么打开？

解压后打开最外层的 index.html，会进入介绍网站。也可以直接打开“产品网站”文件夹里的 index.html。

如果直接打开时遇到浏览器限制，可以在解压后的目录运行 `python -m http.server 8000`，再打开 http://localhost:8000/ 。无需安装项目依赖或执行构建。

上传和更新的方法见 [上线说明](DEPLOYMENT.md)。说明提供中英文，网页目前主要是中文。

请不要把自己的 API 密钥或私人对话记录上传到仓库。本项目目前未附加开源许可证。
